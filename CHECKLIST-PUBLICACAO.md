# Checklist de publicação

- [ ] Criar projeto Supabase
- [ ] Executar `supabase/schema.sql`
- [ ] Configurar `.env.local` localmente (não enviar ao GitHub)
- [ ] Criar e confirmar a conta administradora
- [ ] Conceder role `admin` via SQL, conforme README
- [ ] Testar `npm install`, `npm run dev` e `npm run build`
- [ ] Enviar os arquivos para o GitHub sem segredos
- [ ] Importar repositório na Vercel
- [ ] Configurar variáveis de ambiente na hospedagem
- [ ] Ajustar URLs de autenticação no Supabase
- [ ] Revisar termos, privacidade, LGPD e requisitos legais
- [ ] Não ativar participação paga antes de confirmar autorização legal
- [ ] Testar em celular e computador
